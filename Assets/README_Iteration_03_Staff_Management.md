# RacingGame — Iteration 3: Staff Management

## 1. Что добавлено
Отдельная сцена `Staff.unity` (открывается из Hub по кнопке **STAFF**) с управлением персоналом: 5 саб-табов — **Drivers / Engineers / Leaders / Market / Academy**. Списки строятся из `GameManager.State`, тап по строке открывает детальный попап с полными статами и действиями. Можно нанимать (рынок/академия), увольнять, назначать пилотов на боевые места (Race Seat 1/2). Деньги списываются, состояние сохраняется.

## 2. Что изменилось с прошлой итерации
- `HubController`: кнопка **STAFF** теперь грузит сцену `Staff` (через `tabScenes`), а не показывает заглушку. R&D/CAR/BASE пока остаются заглушками-табами.
- Мульти-класс файлы Итерации 2 (`HubComponents.cs`, `UIComponents.cs`) ранее уже разнесены по отдельным файлам — добавлены новые отдельные: `StaffController`, `StaffSubTab`, `PersonRow`, `PersonDetailPopup`.
- **Фикс:** в `Editor/Iteration2Setup.cs` восстановлена потерянная закрывающая скобка метода `CreateCamera` (в прошлой сборке там была ошибка компиляции). Поэтому переустанови папку целиком.

## 3. Установка
1. Заменить папку `Assets/RacingGame` содержимым архива (перезаписать все файлы — это чинит и `Iteration2Setup.cs`).
2. **Дождаться полной компиляции** (спиннер справа внизу пропал, в Console нет красных ошибок). Только потом жать меню.
3. Прогнать меню по порядку, чтобы пересобрать сцены и Build Settings:
   - **RacingGame → Iteration 1 - Foundation & Main Menu**
   - **RacingGame → Iteration 2 - HQ Hub**
   - **RacingGame → Iteration 3 - Staff Management** (соберёт `Staff.unity`, откроет её)

## 4. Как тестировать
1. Запуск из MainMenu → New Career → Hub → нажать **STAFF** (откроется сцена Staff). Либо открыть `Staff.unity` и Play напрямую (создастся тестовая карьера).
2. Переключить саб-табы Drivers / Engineers / Leaders / Market / Academy — списки заполняются, активный таб подсвечен, у строки бейдж (RACE/RESERVE/тип).
3. Тап по строке → попап со статами. В **Market** нажать Hire → деньги уменьшаются (анимация счётчика), человек переходит в свой таб; кнопка Hire серая, если денег не хватает. У своего пилота в попапе — Race Seat 1/2 и Release (резервиста). **Academy** — подписать проспекта за полцены. Back (←) → возврат в Hub.

## 5. Ожидаемый результат (визуально)
Тёмный экран: топбар (Back, «STAFF», чип денег), под ним строка из 5 саб-табов с акцентным индикатором под активным, ниже — прокручиваемый список карточек (имя, подпись, бейдж, число рейтинга, кнопка действия в Market/Academy). Попап появляется через scale + затемнение; бары статов заполнены. Нажатия — punch + звук, найм — звук успеха, нехватка денег/запрет — звук ошибки. Safe area, вертикаль, текст английский, иконки процедурные.

## 6. Известные ограничения текущей итерации
- Уволить можно только резервиста; чтобы освободить боевого пилота — сначала поставь на его место другого (Race Seat) или сделай резервистом.
- Рынок/найм пока без трансферных переговоров и зарплатного бюджета по сезонам — найм списывает разовую стоимость (зарплата; академия — половина).
- Инженеров пока нельзя переназначать по департаментам из этого экрана (придёт с R&D, Итерация 4).
- Звук синтетический, музыки нет.
