# RacingGame — Iteration 7: GP Weekend (Practice → Qualifying → Race)

## 1. Что добавлено
Отдельная сцена `Weekend.unity` — полный гоночный уикенд по фазам в одном экране:
- **Practice** — инфо о гонке (трасса, страна, круги, длина, дождь) + твои 2 болида (Car/Setup). Кнопка **Run Practice** → **To Qualifying**.
- **Qualifying** — **Run Qualifying** считает квалу всех 22 машин (perf болида + стат Qualifying пилота + сетап), показывает стартовую решётку (P1–P22, гэпы, твои подсвечены) → **To Race**.
- **Race** — живая 2D-симуляция сверху: трасса замкнутой петлёй, 22 точки-болида едут по ней (твои крупнее/акцентные), timing tower с живым переупорядочиванием позиций и гэпами, счётчик кругов, скорость **1x/2x/4x** и **Skip**.
- **Results** — итоговая классификация (очки 25-18-15-12-10-8-6-4-2-1), сводка (лучший финиш / очки / позиция в Кубке конструкторов). **Finish** записывает результаты, обновляет личный и конструкторский зачёт, продвигает неделю/раунд, автосейв и возврат в Hub.

Вход: карточка **Next Race** в Hub теперь запускает уикенд.

## 2. Что изменилось с прошлой итерации
- `HubController`: карточка Next Race грузит сцену `Weekend` (вместо попапа календаря) — мелкая правка.
- Новые файлы: `WeekendController`, `TimingRow`, `Editor/Iteration7Setup`. Переиспользован `PersonRow` (решётка квалы и таблица результатов). Точки-болиды, маркеры трассы и строки timing tower спавнит контроллер в рантайме.

## 3. Установка
1. Заменить папку `Assets/RacingGame` содержимым архива (перезаписать файлы).
2. **Дождаться полной компиляции** (спиннер пропал, в Console нет красных ошибок). Только потом жать меню.
3. Прогнать меню по порядку: **Iteration 1 → 2 → 3 → 4 → 5 → 6 → 7** (последнее соберёт `Weekend.unity`).

## 4. Как тестировать
1. MainMenu → New Career → Hub → нажать карточку **Next Race** → сцена Weekend.
2. **Run Practice → To Qualifying → Run Qualifying** (решётка) → **To Race**. Гонка едет: точки двигаются по трассе, башня переупорядочивается, счётчик кругов идёт; попробуй **2x/4x** и **Skip**.
3. На финише — Results с очками. **Finish** → возврат в Hub: следующая гонка сменилась; зайди заново — в зачёте накопились очки. Можно проезжать календарь гонку за гонкой.

## 5. Тюнинг ощущения гонки
Параметры в начале `WeekendController.cs` (константы), меняются в одну строку:
- `BaseRaceSeconds` — длительность гонки при 1x (по умолчанию 30 с).
- `DisplayLapSeconds` — масштаб гэпов в секундах (визуальный).
- `DnfBasePerSecond` — частота сходов (DNF).
- `NoiseAmp` — «дёрганость»/частота смен позиций.
- `DotLerp` / `TowerLerp` — плавность движения точек и переезда строк башни.
Если после запуска темп/визуал захочется подкрутить — напиши, подскажу значения (без пересборки архива).

## 6. Известные ограничения текущей итерации
- Трасса схематична (эллипс-петля), одинаковой формы для всех гонок; различие трасс отражено в длине/кругах/погоде, влияющих на оптимум сетапа и темп.
- Гонка завершается по пересечению финиша лидером (остальные классифицируются по дистанции/кругам) — без отдельной анимации каждого финиша.
- Practice пока «лёгкий» (без отдельной телеметрии), как договаривались.
- Шины/пит-стопы/стратегия и погодная динамика по ходу гонки — в следующих итерациях.
- Звук синтетический, музыки нет.
