# RacingGame — Iteration 10: Polish (финальная)

## 1. Что изменено
- **Скорость гонки замедлена ~2.5×** — `BaseRaceSeconds` в `WeekendController` 30 → 75. Болиды едут заметно медленнее и читаемее; контроль скорости **1x/2x/4x** и **Skip** на месте (можно ускорить при желании).
- **Juice-пасс: плавное появление строк списков** — компонент `PersonRow` теперь при показе делает мягкий fade + scale-in (DOTween, лёгкий каскад по строкам). Работает сразу на **всех** экранах со списками: Staff, R&D, Car (BUILD), Base, Finance (Sponsors), Standings, решётка квалы и таблица результатов уикенда — без правок их контроллеров.

По твоему фидбэку экономика оставлена как есть, известных багов нет — не трогал.

## 2. Что НЕ менялось (важно для установки)
- **Никаких editor/scene-правок в этой итерации.** Изменены только два рантайм-скрипта: `WeekendController.cs` и `PersonRow.cs`.
- Поэтому **перепрожимать меню не нужно** — достаточно заменить файлы и дождаться компиляции. (Сцены не пересобираются.)

## 3. Установка
1. Заменить папку `Assets/RacingGame` содержимым архива (перезаписать файлы).
2. Дождаться компиляции (в Console нет красных ошибок).
3. Запустить — всё. Меню Iteration 1–9 перепрожимать не требуется (если они уже были прогнаны ранее).

## 4. Как проверить
1. Hub → Next Race → дойти до Race: болиды едут медленнее, гонку комфортнее смотреть на 1x; 2x/4x ускоряют.
2. Открой любой список (Staff / R&D / Car / Base / Finance → Sponsors / Standings): строки появляются с лёгким fade+scale, при переключении саб-табов — тоже.

## 5. Тонкая подстройка (если нужно)
- Скорость гонки: `BaseRaceSeconds` в `WeekendController.cs` (больше = медленнее). Сейчас 75; хочешь ещё медленнее — ставь 90–100, быстрее — 50–60.
- Анимация строк: в `PersonRow.cs` — длительности `0.2`/`0.24`, задержка-каскад `0.022` (множитель на индекс), потолок `0.28`. Убрать каскад — `delay = 0`.

## 6. Итог по плану
Это финальная, 10-я итерация плана. Реализованный костяк: Foundation/Main Menu → HQ Hub → Staff → R&D → Car (Build+Setup) → Facilities → GP Weekend (Practice/Qualifying/2D-Race/Results) → Finances+Sponsors+Data→R&D → Season Rollover+Standings → Polish.
