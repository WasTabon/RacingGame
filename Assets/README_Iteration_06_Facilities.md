# RacingGame — Iteration 6: Facilities (Base)

## 1. Что добавлено
Отдельная сцена `Base.unity` (открывается из Hub по кнопке **BASE**) — одноэкранный раздел сооружений базы: топбар (Back, «FACILITIES», деньги) и прокручиваемый список. Сверху строка-сводка «Base HQ» со средним уровнем сооружений, ниже 5 строк: **Factory / Wind Tunnel / Simulator / Material Lab / Data Center** — уровень, краткий эффект и кнопка **Upgrade** (списывает деньги, +1 уровень, потолок 10, стоимость `(level+1)×8M`). Кнопка серая при нехватке денег или на максимуме.

## 2. Что изменилось с прошлой итерации
- `HubController`: добавлен переход на сцену `Base` по кнопке **BASE** (`tabScenes[4] = "Base"`, одна строка). **Теперь все 5 кнопок нижней навигации Hub рабочие** (HQ — обзор в самом Hub; STAFF / R&D / CAR / BASE — свои сцены).
- Новые файлы: `BaseController`, `Editor/Iteration6Setup`. Переиспользован `PersonRow` (строки). Новых компонентов нет.

## 3. Установка
1. Заменить папку `Assets/RacingGame` содержимым архива (перезаписать файлы).
2. **Дождаться полной компиляции** (спиннер справа внизу пропал, в Console нет красных ошибок). Только потом жать меню.
3. Прогнать меню по порядку, чтобы пересобрать сцены и Build Settings:
   - **Iteration 1 - Foundation & Main Menu**
   - **Iteration 2 - HQ Hub**
   - **Iteration 3 - Staff Management**
   - **Iteration 4 - R&D**
   - **Iteration 5 - Car**
   - **Iteration 6 - Facilities** (соберёт `Base.unity`, откроет её)

## 4. Как тестировать
1. Запуск из MainMenu → New Career → Hub. Проверить, что все 5 кнопок снизу открывают свои экраны (HQ остаётся в Hub, остальные — переход в сцену и Back обратно).
2. Нажать **BASE** → сцена Base. Нажать **Upgrade** у сооружения → уровень и сводка Base Rating растут, деньги списываются; кнопка серая при нехватке/максимуме (LV 10). Back (←) → Hub.
3. Либо открыть `Base.unity` и Play напрямую (создастся тестовая карьера).

## 5. Ожидаемый результат (визуально)
Тёмный экран: топбар (Back, «FACILITIES», чип денег), под ним прокручиваемый список — строка-сводка (бейдж BASE, средний уровень) и 5 карточек сооружений (имя, эффект, бейдж LV, число уровня, кнопка Upgrade). Нажатия — punch + звук, Upgrade — звук успеха, нехватка/максимум — звук ошибки + серая кнопка, счётчик денег анимируется. Safe area, вертикаль, текст английский, иконки процедурные.

## 6. Известные ограничения текущей итерации
- Апгрейды мгновенные (поля `isUpgrading`/`upgradeWeeksRemaining` оставлены под будущий сезонный таймер, как с проектами R&D).
- Эффекты сооружений показаны текстом-флавором; реальное влияние на сборку/R&D/гонку подключится в следующих системах (уикенд и сезон).
- Base Rating — округлённый средний уровень сооружений.
- Звук синтетический, музыки нет.
