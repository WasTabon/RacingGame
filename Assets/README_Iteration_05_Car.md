# RacingGame — Iteration 5: Car Construction & Setup

## 1. Что добавлено
Отдельная сцена `Car.unity` (открывается из Hub по кнопке **CAR**) с двумя саб-табами:
- **BUILD** — по каждому из 2 болидов строка-заголовок (имя + Overall Performance) и 4 строки групп компонентов: **Aerodynamics**, **Engine**, **Chassis**, **Reliability**. Кнопка **Develop** списывает деньги и поднимает характеристики группы у этого болида (потолок 100). Это прямое вложение денег в конкретную машину.
- **SETUP** — селектор болида (Car 1 / Car 2), 3 слайдера (**Downforce / Balance / Reliability**, сохраняются в сетап болида), большой **Setup Rating** с баром, который вживую пересчитывается по близости к оптимуму ближайшей трассы, и кнопка **Auto Setup** (мгновенно подгоняет слайдеры под оптимум → рейтинг 100). Тюнинг бесплатный.

## 2. Что изменилось с прошлой итерации
- `HubController`: добавлен переход на сцену `Car` по кнопке **CAR** (`tabScenes[3] = "Car"`, одна строка). BASE остаётся заглушкой-табом.
- Новые файлы: `CarController`, `Editor/Iteration5Setup`. Переиспользованы `StaffSubTab` (саб-табы и селектор болида) и `PersonRow` (строки BUILD); слайдеры — как в Settings.
- Оптимум сетапа выводится детерминированно из параметров ближайшей гонки (длина круга, число кругов, шанс дождя) — стабильный и предсказуемый; формулу можно поправить отдельной мелкой правкой.

## 3. Установка
1. Заменить папку `Assets/RacingGame` содержимым архива (перезаписать файлы).
2. **Дождаться полной компиляции** (спиннер справа внизу пропал, в Console нет красных ошибок). Только потом жать меню.
3. Прогнать меню по порядку, чтобы пересобрать сцены и Build Settings:
   - **Iteration 1 - Foundation & Main Menu**
   - **Iteration 2 - HQ Hub**
   - **Iteration 3 - Staff Management**
   - **Iteration 4 - R&D**
   - **Iteration 5 - Car** (соберёт `Car.unity`, откроет её)

## 4. Как тестировать
1. Запуск из MainMenu → New Career → Hub → нажать **CAR** (откроется сцена Car). Либо открыть `Car.unity` и Play напрямую (создастся тестовая карьера).
2. **BUILD**: нажать **Develop** у группы (например Aerodynamics) → её рейтинг и Overall растут, деньги списываются; вернуться в Hub — бары болидов выше. Кнопка серая при нехватке денег или достижении 100.
3. **SETUP**: подвигать слайдеры → Setup Rating меняется вживую; нажать **Auto Setup** → рейтинг 100; переключить Car 1 / Car 2 (у каждого свой сетап). Back (←) → Hub.

## 5. Ожидаемый результат (визуально)
Тёмный экран: топбар (Back, «CAR», чип денег), 2 саб-таба с акцентным индикатором. В BUILD — прокручиваемый список карточек (группа, рейтинг, кнопка Develop). В SETUP — селектор болида, инфо о трассе, 3 слайдера с процентами, крупный Setup Rating с баром, кнопка Auto Setup внизу. Нажатия — punch + звук, Develop/Auto — звук успеха, нехватка денег — звук ошибки + серая кнопка, счётчик денег анимируется, слайдеры тянутся плавно. Safe area, вертикаль, текст английский, иконки процедурные.

## 6. Известные ограничения текущей итерации
- Группы развиваются по +5 за нажатие (равномерно по характеристикам группы); поатрибутной точечной прокачки нет.
- Setup Rating считается от детерминированного оптимума трассы (заглушка под будущую физику уикенда) — на саму гонку пока не влияет (повлияет в Итерации 7).
- Сетап сохраняется per-car; общий «оптимум» берётся для ближайшей гонки сезона.
- Develop и анлоки деревьев из R&D складываются (оба поднимают характеристики болида).
- Звук синтетический, музыки нет.
