# RacingGame — Iteration 2: HQ Hub + Навигация + Обзор команды

## 1. Что добавлено
Полноценный главный экран управления командой (HQ Hub): верхняя панель с анимированными счётчиками денег и репутации, нижняя навигация из 5 разделов и рабочая вкладка **Team Overview** с карточками пилотов, барами производительности болидов и карточкой ближайшей гонки. Тап по карточке гонки открывает попап календаря сезона (22 этапа) с прокруткой. Всё читается из реального `GameManager.State`.

## 2. Что изменилось с прошлой итерации
- Сцена `Hub.unity` пересобрана из заглушки Итерации 1 в полноценный экран (editor-скрипт Итерации 2 перезаписывает сцену).
- В `IconFactory` добавлены процедурные иконки: `home`, `staff`, `research`, `car`, `facility`, `chevron` (изменён только этот файл из Итерации 1, дополнение — старые иконки и меню Итерации 1 работают как прежде).
- В сцену Hub добавлен объект `Managers`, чтобы хаб запускался автономно; при входе из MainMenu дубликат менеджеров корректно уничтожается (persistent-синглтоны сохраняются).

## 3. Установка (ЧИСТАЯ — важно)
Чтобы гарантированно убрать ранее побитую сцену и устаревшие ссылки на скрипты:
1. В Unity удалить целиком папку `Assets/RacingGame` (правки не теряются — их нет; сейв в PlayerPrefs сохраняется).
2. Распаковать архив в `Assets/` (появится свежая `Assets/RacingGame`).
3. **Дождаться полной компиляции**: индикатор-спиннер в правом нижнем углу пропал, в Console нет красных ошибок. Только после этого жать меню.
4. Меню **RacingGame → Iteration 1 - Foundation & Main Menu** (пересоберёт MainMenu).
5. Меню **RacingGame → Iteration 2 - HQ Hub** (пересоберёт Hub и откроет его).

Важно: НЕ запускать меню, пока Unity компилирует — иначе ссылки на скрипты могут «протухнуть» (missing script). Каждый MonoBehaviour теперь в отдельном файле с именем класса, что минимизирует этот риск.

## 4. Как тестировать
1. Вариант А (из меню игры): открыть сцену `MainMenu`, нажать Play → **New Career** → выбрать сложность → перейти на Hub с данными выбранной команды.
2. Вариант Б (автономно): открыть сцену `Hub`, нажать Play — если карьеры нет, автоматически создаётся тестовая на Normal.
3. На Hub проверить: счётчики денег/репутации плавно «накручиваются»; переключение вкладок снизу (HQ / STAFF / R&D / CAR / BASE) с подсветкой активной и звуком; на вкладке HQ — 2 карточки пилотов (имя, возраст, POT, OVR + бары SPD/QUAL/CONS) и 2 бара болидов анимируются; тап по карточке **Next Race** открывает попап календаря, прокрутка работает, кнопка закрытия закрывает; кнопка-шестерёнка открывает Settings.

## 5. Ожидаемый результат (визуально)
Тёмный экран в стиле менеджера: вверху sticky-панель с монетой ($X.XM) и звездой репутации, по центру название команды + философия, секции DRIVERS и CARS с барами, снизу sticky-навбар с 5 иконками. Бары заполняются анимацией Ease.OutQuad, попапы появляются через scale OutBack с затемнением фона, кнопки дают punch + звук + вибро. Всё в safe area (вырез/home indicator учтены), вертикальная ориентация, текст на английском.

## 6. Известные ограничения текущей итерации
- Вкладки **STAFF / R&D / CAR / BASE** — стилизованные заглушки («Coming in Iteration N»), наполнятся в итерациях 3–6.
- Попап календаря показывает данные, но переход к самой гонке ещё не реализован (Итерация 7).
- Звуки синтетические (синусоиды-плейсхолдеры), музыки пока нет.
- Если DOTween только что импортирован и в консоли ошибки на `DOFade`/`DOFillAmount` — открыть **Tools → Demigiant → DOTween Utility Panel → Setup DOTween…** (включить UI-модули).
