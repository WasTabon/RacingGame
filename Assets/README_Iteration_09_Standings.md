# RacingGame — Iteration 9: Season Rollover + Standings

## 1. Что добавлено
- **Сцена Standings** (`Standings.unity`) — открывается **тапом по чипу репутации** («★ …») в Hub (симметрично чипу денег → Finance). 2 саб-таба:
  - **DRIVERS** — личный зачёт пилотов по очкам (позиция, имя, команда, очки, победы).
  - **TEAMS** — Кубок конструкторов по очкам.
  Заголовок «Season YYYY • Round N»; твои пилоты/команда подсвечены акцентом, топ-3 — медальными цветами.
- **Season Rollover** — после финиша **последней гонки** сезона автоматически:
  - Призовые за итог Кубка конструкторов по финальным позициям (всем командам, $50M…$5M линейно).
  - `seasonYear++`, новый календарь (22 гонки, сброс completed/результатов, новая погода/круги/длина), `currentRound=1`, `currentWeek=1`.
  - Сброс зачётов (личный + конструкторов) и посезонных счётчиков в 0.
  - Старение: пилоты и инженеры +1 год; контракты пилотов/инженеров/персонала −1.
  - Репутация игрока меняется по итоговой позиции (чемпион → заметно растёт, открывает спонсоров).
  - **Живой мир:** AI-команды развивают болиды между сезонами (+рост характеристик, капед 100).
  - На экране **Results** последней гонки вместо строки Payout показывается «SEASON YYYY COMPLETE — Champion … • You Pn • Prize …». **Finish** применяет rollover и возвращает в Hub уже с новым сезоном.

## 2. Что изменилось с прошлой итерации
- `WorldGenerator` — методы `RolloverSeason(state)` и `SeasonPrize(pos, count)`.
- `WeekendController` — триггер rollover после последней гонки + сводка сезона на Results.
- `HubController` — чип репутации грузит сцену `Standings`.
- `Iteration2Setup` — чип репутации стал кнопкой (поэтому Hub снова пересобирается; чип денег из Итерации 8 тоже остаётся кнопкой).
- Новые файлы: `StandingsController`, `Editor/Iteration9Setup`. Переиспользованы `StaffSubTab` и `PersonRow`.

## 3. Установка
1. Заменить папку `Assets/RacingGame` содержимым архива (перезаписать файлы).
2. **Дождаться полной компиляции** (в Console нет красных ошибок).
3. Прогнать меню по порядку: **Iteration 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9**. (Важно: меню Iteration 2 пересоберёт Hub — теперь оба чипа кликабельны; Iteration 9 соберёт `Standings.unity`.)

## 4. Как тестировать
1. MainMenu → New Career → Hub → тап по **чипу репутации** → сцена Standings (DRIVERS / TEAMS). После пары гонок там видны очки.
2. Проезжай гонки до конца сезона (можно быстро через **Skip** в уикенде). На **последней** гонке Results покажет «SEASON … COMPLETE». **Finish** → вернись в Hub: год сменился (Week 1), календарь новый, зачёты обнулились, деньги выросли на призовые, репутация изменилась.
3. После rollover открой Standings — зачёты пустые (новый сезон); зайди к спонсорам в Finance — при выросшей репутации могли открыться новые предложения.

## 5. Параметры тюнинга (константы)
- `WorldGenerator.cs`: `SeasonPrizeTop` / `SeasonPrizeBottom` (призовые за 1-е/последнее место в Кубке).
- AI-развитие: коэффициент `Random.Range(2f, 6f)` в `RolloverSeason` (насколько AI прибавляют за сезон).
- Репутация за итог сезона: формула `Mathf.Clamp(6 - pos*2, -3, 8)` в `RolloverSeason`.
Если рост AI/призовые/репутация покажутся слишком резкими или слабыми — напиши, подскажу значения.

## 6. Известные ограничения текущей итерации
- Трансферов пилотов между командами пока нет — контракты только уменьшаются (минимум 1, без авто-ухода во free agency).
- Очень старые пилоты не уходят на пенсию и новые молодые не генерятся (старение только инкрементальное).
- AI-развитие равномерное (общий бамп характеристик), без индивидуальных стратегий команд.
- Standings — только текущий сезон (история прошлых сезонов не хранится).
- Звук синтетический, музыки нет.
