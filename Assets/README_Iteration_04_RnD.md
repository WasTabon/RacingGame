 й # RacingGame — Iteration 4: R&D (Departments + Tech Trees)

## 1. Что добавлено
Отдельная сцена `RnD.unity` (открывается из Hub по кнопке **R&D**) с двумя саб-табами:
- **DEPTS** — 5 департаментов (Aero/Engine/Chassis/Materials/Simulation): уровень, output rating, число инженеров. Кнопка **Upgrade** поднимает уровень за деньги (output = level×20, до уровня 5).
- **TECH** — 4 дерева технологий (Aerodynamics/Engine/Materials/Electronics), у каждого 5 узлов по уровням. Узлы открываются последовательно: кнопка **Unlock** на ближайшем доступном узле списывает деньги, открывает узел и применяет его прирост к обоим болидам команды (видно по барам в Hub).

## 2. Что изменилось с прошлой итерации
- `HubController`: добавлен переход на сцену `RnD` по кнопке **R&D** (`tabScenes[2] = "RnD"`, одна строка). CAR/BASE пока остаются заглушками-табами.
- Новые файлы: `RnDController`, `Editor/Iteration4Setup`. Переиспользованы `StaffSubTab` (саб-табы) и `PersonRow` (строки) — без новых дублей.
- Проекты/прототипирование и назначение инженеров по департаментам сознательно отложены (по договорённости урезали объём).

## 3. Установка
1. Заменить папку `Assets/RacingGame` содержимым архива (перезаписать файлы).
2. **Дождаться полной компиляции** (спиннер справа внизу пропал, в Console нет красных ошибок). Только потом жать меню.
3. Прогнать меню по порядку, чтобы пересобрать сцены и Build Settings:
   - **RacingGame → Iteration 1 - Foundation & Main Menu**
   - **RacingGame → Iteration 2 - HQ Hub**
   - **RacingGame → Iteration 3 - Staff Management**
   - **RacingGame → Iteration 4 - R&D** (соберёт `RnD.unity`, откроет её)

## 4. Как тестировать
1. Запуск из MainMenu → New Career → Hub → нажать **R&D** (откроется сцена RnD). Либо открыть `RnD.unity` и Play напрямую (создастся тестовая карьера).
2. **TECH**: у дерева открыт только первый узел; нажать **Unlock** на узле с бейджем NEXT → деньги списались, узел стал UNLOCKED, следующий стал NEXT. Вернуться в Hub — бары болидов чуть выросли.
3. **DEPTS**: нажать **Upgrade** у департамента → уровень и output растут, деньги уменьшаются. Кнопка серая, если денег не хватает или достигнут максимум (LV 5). Back (←) → Hub.

## 5. Ожидаемый результат (визуально)
Тёмный экран: топбар (Back, «R&D», чип денег), под ним 2 саб-таба с акцентным индикатором под активным, ниже — прокручиваемый список строк (имя, подпись, бейдж статуса, число, кнопка действия). В TECH перед узлами каждого дерева идёт строка-заголовок (имя дерева, бейдж TREE, X/5 unlocked). Нажатия — punch + звук, успех апгрейда/анлока — звук успеха, нехватка денег — звук ошибки + серая кнопка, счётчик денег анимируется. Safe area, вертикаль, текст английский, иконки процедурные.

## 6. Известные ограничения текущей итерации
- Проектов/прототипирования (5 стадий) пока нет — перенесено на будущую итерацию.
- Инженеров пока нельзя назначать/снимать по департаментам из этого экрана (число инженеров показывается, но переназначение — позже).
- Узлы дерева открываются строго по порядку (нельзя перепрыгнуть уровень).
- Апгрейд департамента улучшает output rating, но без проектов он пока не влияет на машину напрямую (повлияет, когда добавим проекты).
- Звук синтетический, музыки нет.
